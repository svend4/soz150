# Writing OS

Прототип AI-помощника для подготовки немецких социально-правовых документов по темам SGB IX, SGB XII и SGG. Описание проекта предусматривает выбор контекста и навыков, генерацию и выполнение кода в браузере, а также проверку утверждений в документе.

Краткая архитектура и состояние проекта описаны в `WRITING_OS_HANDOFF (1).md`.
